# 📱 Application de Coloriage pour Enfants

## 🎨 Fonctionnalités
- 26 lettres de l'alphabet à colorier (A-Z)
- 20+ animaux à colorier
- 13 couleurs disponibles
- Interface en français
- Pour enfants

## 📦 Téléchargement
L'APK est généré automatiquement par GitHub Actions à chaque push.

**Dernière compilation:** 2025-11-18

## 🔗 Lien pour télécharger
Après que le build soit terminé (✅ vert), téléchargez l'APK ici:
https://github.com/Rythmique/cadeau-de-claude/actions

Cliquez sur le workflow le plus récent → Section "Artifacts" → Téléchargez "app-debug"
